Questions

Which repositories work?
Public Python, JavaScript/TypeScript and Rust repositories.
What if DevSwarm can't push to the repository?
It forks it and opens the pull request in the fork. You get a link to propose it to the original project yourself.
Is my run private?
No. Everything a run does is shown publicly here.
Is it safe to run on any code?
Every command runs in a Docker container with no network and no secrets.
Why do I need an access code?
Each fix spends API credits, so submitting is limited to people with a code, with queue and daily limits.
